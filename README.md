# NeuroNexus
Web development tasks for NeuroNexus internship.

This repository contains the solutions for the web development tasks.

## Task 1: Web Form (HTML & CSS)

This directory contains the files for the first task, which involves creating a web form using only HTML and CSS.

### Contents

* `index.html`: Defines the structure and content of the registration form.
* `styles.css`: Provides the styling for the registration form, including layout and visual enhancements.

### Description

The form collects the following user details:

* Full Name
* Contact Number
* Address
* Company Name
* Email Address
* Department (Dropdown: HR, Sales, Development, Marketing, Others)
* Gender (Radio Buttons: Male, Female, Prefer not to say)

It also includes a submit button and basic styling.
